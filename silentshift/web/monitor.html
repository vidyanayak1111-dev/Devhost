A match with another build of the same model points at serving (quantisation), not the model.

Or change it from any terminal

Works on the Ollama computer, or remotely through a Cloudflare link. Python only, no packages.

cd provider_tools
python provider.py swap llama3.2:1b     # MODEL layer
python provider.py quant                # SERVING: q8 build
python provider.py context 512          # SERVING: context
python provider.py slow                 # SERVING: hardware
python provider.py safety               # SAFETY layer
python provider.py normal               # back to normal
python provider.py swap gemma3:1b --url https://xxx.trycloudflare.com

Windows: double-click provider_tools\change_bot_latest.bat for a menu.

Privacy audit

SilentShift stores no user prompts. The audit sends a unique secret through the chatbot path, then scans every file SilentShift has written for it.

Everything SilentShift stores about model calls

probe = canary from the monitor, live = chatbot message. IN/OUT = tokens read/written, TOK/S = speed, settings hash = fingerprint of the request settings. No text. (Ollama re-uses work on repeated prompts, so IN can be small.)

PS-03 constraints

  • No provider internals: only answers, token counts and timing
  • No user prompts stored - checked by the privacy audit
  • Normal variation: baseline learns the spread; a clue must appear in two rounds
  • Probe cost: 15 calls when quiet, more only when something looks off - shown on every report
  • Report separates observed evidence from likely cause, lists alternatives and what it can't prove
  • Randomised controlled changes: detection, attribution, false alarms, missed, cost - plus identification
